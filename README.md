# زينة النيل — النسخة المطابقة للمرجع

واجهة متجر Next.js عربية RTL مبنية لتطابق تصميم زينة النيل المرجعي:
- هيدر كحلي وذهبي
- لوجو كبير
- شريط بحث مركزي
- أرقام مصر والإمارات
- الشحن إلى مصر والإمارات وقطر
- بانر رئيسي
- أقسام التوب والإكسسوارات
- منتجات الأكثر مبيعًا
- أيقونات السلة والمفضلة والحساب
- تصميم متجاوب

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```
